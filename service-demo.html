LumaTube foreground-service demonstration

This screen recording shows the real Android application running on an API 35 emulator. The recording begins with an active user-requested transfer. It shows the notification while the app is in the background, then the downloads screen, MP3 processing and completion. The app uses FOREGROUND_SERVICE_DATA_SYNC for the requested transfer, media processing and saving to shared media storage. Transfers are user initiated and can be paused or cancelled. No production ad was requested for this recording.
